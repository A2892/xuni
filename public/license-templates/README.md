# 驾照模板图片使用说明

## 如何添加真实驾照模板图片

1. 将您的驾照模板图片（如您之前分享的Virginia驾照图片）保存到这个文件夹
2. 将图片重命名为 `virginia-template.jpg` 或 `virginia-template.png`
3. 刷新网页即可看到效果

## 图片要求

- 推荐尺寸：1080x680 像素（或等比例）
- 支持格式：JPG、PNG
- 建议使用高清图片以获得最佳效果

## 当前实现

代码会自动：
1. 加载真实驾照图片作为背景
2. 在原有信息区域覆盖白色半透明遮罩
3. 在相应位置写入您填写的新信息
4. 保留背景图片的所有装饰元素（条形码、徽章等）

这样可以实现在真实驾照照片上直接修改信息的效果！
